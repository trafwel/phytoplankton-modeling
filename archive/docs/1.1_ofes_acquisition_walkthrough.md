# Walkthrough — 1.1 OFES Arabian Sea Surface Temperature Acquisition

A step-by-step guide for *you* to implement the OFES download. All the hard-won
constants (endpoint, grid indices, fill value, time axis) are verified live and
listed up front so you don't have to re-derive them. The skeleton at the bottom
is a template to fill in, not finished code.

## Verified reference values (use these directly)

| Thing | Value | How to use it |
|---|---|---|
| OPeNDAP endpoint | `http://apdrc.soest.hawaii.edu/dods/public_ofes/OfES/ncep_0.1_global_3day/temp` | Open with `xarray.open_dataset(url, decode_times=False)` |
| Variable | `temp` (potential temperature, °C) | Rename to `sst` on save |
| Dimensions | `temp[time=5600][lev=54][lat=1500][lon=3600]` (Float32) | — |
| lat axis | −74.95 … 74.95, step 0.1, `degrees_north` | Select `slice(5.0, 25.0)` |
| lon axis | 0.05 … 359.95, step 0.1, `degrees_east` (0–360) | Select `slice(50.0, 75.0)` |
| lev axis | 2.5 m (index 0) … 5900 m | Surface = `isel(lev=0)` |
| time axis | 3-day steps, `03jan1980` → `29dec2025` (public 3D: 1980–2014) | Build yourself (see below) |
| Fill / land value | `-1.0E34` | Mask with `.where(x > -5e33)` |
| Study window (locked) | 1998–2014 | Keep ≤ 2014 (2015+ is IPRC-restricted) |
| Box (locked) | Arabian Sea 5–25°N, 50–75°E, surface | — |

**Time axis gotcha:** the server reports `units = "days since 1-1-1"`, which
non-standard decoders choke on. Don't let xarray decode it. Instead build the
axis yourself — it's a clean 3-day cadence:
`pandas.date_range(start="1980-01-03", periods=5600, freq="3D")`. Then map your
desired years to integer positions on that axis.

## Step-by-step

**Step 1 — Environment.** Create a fresh env and install: `xarray`, `netCDF4`,
`pydap` (the OPeNDAP backend), `numpy`, `pandas`. Confirm `import pydap` works —
if xarray can't find a DAP backend, the remote open fails silently-ish.

**Step 2 — Folder layout.** Make `data/raw/ofes_temp/` (per-year files) and
`data/interim/` (merged file). Keeping yearly files separate is what lets you
resume after the flaky server drops a connection.

**Step 3 — Open the endpoint.** `xr.open_dataset(URL, decode_times=False)`.
Print `ds["temp"].sizes` to confirm you actually connected (you'll see the
5600×54×1500×3600 dims). This is a lazy handle — no data moves yet.

**Step 4 — Build the real time index** (Step 1 gotcha). Then write a tiny helper
that, given a year, returns the first/last integer index where
`time_index.year == year`. You'll feed those to `isel(time=slice(t0, t1+1))`.

**Step 5 — Subset one year.** For each year:
  - spatial: `ds["temp"].sel(lat=slice(5,25), lon=slice(50,75))` — select by
    coordinate *value*, not index, so you're robust to half-cell offsets.
  - vertical: `.isel(lev=0)` for the surface.
  - temporal: `.isel(time=slice(t0, t1+1))`.
  - `.load()` — **this** is the slow network call that pulls the bytes.
  - mask land: `.where(sub > -5e33)`.
  - attach real dates: `assign_coords(time=time_index[t0:t1+1])`.
  - rename to `sst`, add `units="degC"` and a `region` attribute.
  - write `data/raw/ofes_temp/ofes_sst_<year>.nc`.

**Step 6 — Retry / resume wrapper.** Wrap Step 5 in a loop with ~4 attempts and
a ~20 s sleep between them. On failure, re-open the endpoint (APDRC drops
sessions). At the top of each year, `if os.path.exists(fpath): skip` so re-runs
resume instead of re-downloading.

**Step 7 — Concatenate.** After the loop, `xr.open_mfdataset(sorted(files),
combine="by_coords")` and write one merged NetCDF to `data/interim/`.

**Step 8 — Verify (do not skip).** Open the merged file; check the time span is
continuous, plot a single SST map with coastlines, and confirm land is NaN and
ocean is ~24–30 °C. This is your Phase 1 exit check.
